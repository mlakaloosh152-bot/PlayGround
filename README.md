## NIGHTFALL — Outbreak Protocol

A self-contained, browser-playable top-down survival shooter. Clear escalating enemy waves, collect ammo and med kits, and see how long you can hold Sector 09.

### Controls

- **WASD / arrow keys** — move
- **Mouse** — aim; hold left mouse button to fire
- **R** — reload
- **Space** — dash
- **P / Esc** — pause
- **Touchscreens** — virtual stick, fire, reload, and dash controls

Open `index.html` directly, or serve this folder with any static web server.
